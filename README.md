# TypeFoundry — Project 005

A neo-brutalist typography playground built with vanilla HTML, CSS and JavaScript.

## Features
- Live editable typography canvas
- 8 Google Fonts
- Font family, weight, style, size, tracking, line-height, alignment and case controls
- Foreground/background colour controls and curated swatches
- Grid and frame overlays
- Five creative presets and randomise
- Typeface specimen library
- Save, load and delete designs
- Copy generated CSS
- Export SVG artwork
- Import/export project JSON
- Local browser autosave and dark appearance
- Responsive layout

## Run locally
Open `index.html` in a modern browser. No build step is needed. Internet is required to load the optional Google Fonts; system fallbacks remain available.

## GitHub Pages
1. Create a repository named `typefoundry`.
2. Extract this ZIP and upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Commit the files.
4. Open Settings → Pages.
5. Select Deploy from a branch, choose `main` and `/ (root)`, then save.

## Storage
Designs are stored in localStorage in the current browser. Export the project JSON to keep a portable backup. Data does not sync automatically across devices.
